# Grill With Docs

A structured alignment protocol before writing substantial code.

## Protocol
1. **Interview the Operator**: Ask high-impact questions one by one about requirements, constraints, edge cases, and performance expectations.
2. **Build Ubiquitous Language**: Record new concepts in `CONTEXT.md` to keep domain terminology concise and consistent.
3. **Record Architectural Decisions**: Create ADRs in `docs/decisions/` whenever choosing between competing approaches.
4. **Agree on Seams**: Define the exact public interfaces to be built and tested.
