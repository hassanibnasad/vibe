# Agent Guidelines & Configuration

This repository (`vibe`) uses agent skills to streamline engineering workflows, architectural design, testing, and issue management.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for this repo (`https://github.com/hassanibnasad/vibe`). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses canonical triage label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo (`CONTEXT.md` at root and `docs/decisions/` for ADRs). See `docs/agents/domain.md`.
